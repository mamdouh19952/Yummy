# Yummy — Meals Explorer

A single-page recipe browser. Search for meals, explore them by category, area, or ingredient, and open the full recipe for any meal.

## Features

- **Search** meals by name or by first letter
- **Browse** by category, area (cuisine), or ingredient
- **Meal details** with ingredients, measures, instructions, and tags
- **Contact form** with input validation
- Responsive layout and animated side menu

## Tech Stack

| Area | Tools |
|---|---|
| Markup / style | HTML5, CSS3, Bootstrap 5, Font Awesome |
| Logic | JavaScript, jQuery (fetch, async/await, DOM) |
| Data | [TheMealDB](https://www.themealdb.com/api.php) public API (no key needed) |

## Project Structure

```
index.html   the single page
js/          app logic (index.js) and libraries
css/         Bootstrap, Font Awesome, custom styles
imgs/        images
```

## Getting Started

It is a static site, so there is no build step. Clone the repo, serve the folder with any static server (for example the VS Code Live Server extension), and open `index.html`.
